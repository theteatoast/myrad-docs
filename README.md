# MYrAD Docs (Docusaurus)

This is a Docusaurus v2 documentation site for MYrAD.

Quick start:

1. Install dependencies: `npm install`
2. Run locally: `npm run start`
3. Build: `npm run build`
4. Serve locally: `npm run serve`

Deploy: push to GitHub and connect the repo to Vercel. Use `npm run build` with output dir `build`.
