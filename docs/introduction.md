# Introduction

**MYRAD** is a decentralized data marketplace that converts datasets into liquid, tradable digital assets through on-chain tokenization and automated market mechanisms.  
Every dataset uploaded to MYRAD is minted as its own **DataCoin (DC)**; an ERC-20 token directly linked to the dataset’s IPFS content identifier (CID).

This structure establishes a transparent, self-sustaining data economy where creators earn automatically, users gain verifiable access, and all participants benefit from shared liquidity and value growth.

## Core Concept

- **Zero-Cost Creator Onboarding:** Creators can publish and tokenize datasets at no cost. The MYRAD Treasury provides the initial liquidity and gas to launch each dataset’s economy.  
- **Automated Value Dynamics:** Each dataset has its own decentralized liquidity pool that enables instant trading, price discovery, and market-driven valuation.  
- **Access-Driven Deflation:** When users access data, the system executes a **buy and burn** event. **50% of the tokens are burned** while **50% return to the pool** to sustain liquidity and balance supply.  
- **Perpetual Availability:** Because only part of each access is burned, datasets remain continuously available while still benefiting from deflationary token mechanics.  
- **Aligned Incentives:** Data creators, consumers, and liquidity providers all participate in the same economic feedback loop, ensuring mutual growth and sustainability.

## The Vision

MYRAD’s goal is to make **data ownership, monetization, and access fully decentralized**.  

By merging blockchain economics with decentralized storage, it creates a new class of digital assets where **data itself becomes currency**, empowering individuals, enterprises, and AI systems to exchange information transparently, efficiently, and fairly.

In essence, MYRAD transforms raw data into an autonomous economic entity, one that **earns, evolves, and circulates** across the decentralized web.
