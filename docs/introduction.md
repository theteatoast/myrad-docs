# Introduction

MYRAD is a decentralized data marketplace that transforms data into a liquid, tradable asset through tokenization and automated market mechanics. Each dataset uploaded becomes its own **DataCoin (DC)**, an ERC20 token backed by on-chain liquidity.

This model rewards data creators, maintains transparent price discovery, and enables sustainable, unlimited access for users and enterprises.

---

## Core Concept

- **Zero-Cost Creator Onboarding:** Creators launch tokens for free, and the protocol covers liquidity seeding and gas.  
- **Partial Burn Mechanics:** Every dataset access triggers an on-chain buy and burn event where **50% of the tokens are burned** and **50% return to the liquidity pool**, ensuring long-term sustainability.  
- **Continuous Accessibility:** Since only part of each access transaction is burned, datasets remain perpetually accessible while still introducing mild deflationary pressure.  
- **Long-Term Alignment:** Creators, users, and liquidity providers benefit from the same growth cycle.

Together, these components create a decentralized, self-sustaining ecosystem where data functions as a liquid, tradable digital asset, combining **monetization, speculation, and open access** in a single unified model.
